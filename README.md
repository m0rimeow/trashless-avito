
# trashless-avito
Tampermonkey script to minimize trash on your homepage and search page, I will try my best to maintain it.
## Features 
- Hides listings marked "Забронировано" 
- Dims listings marked "Просмотрено"
- Removes ad slots that leave empty gaps in the listings grid

 Works on the homepage and in the search results

## Installation
- Get [Tampermonkey](https://www.tampermonkey.net/)
- Click on [this](https://raw.githubusercontent.com/m0rimeow/trashless-avito/main/avito-without-trash.user.js) link, wait for a pop-up from Tampermonkey
- Have fun ig
